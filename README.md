# TripFlow

여행 전 예산과 저축계획, 환율 시뮬레이션, 여행 중 지출 관리, 공동 여행자금, 정산, 리포트를 한 번에 다루는 Streamlit 앱입니다.

## 기능

| 페이지 | 내용 |
|---|---|
| 1 여행 전 계획 | 여행지·날짜·인원·스타일·보유금액 입력 → 항목별 예상 여행비, 1인 목표금액, 월별·주별 저축액, 누적 저축 그래프. 항공권 가격을 바꾸면 즉시 재계산되고, 저장하면 여행이 만들어집니다. |
| 2 환율 | 현재 환율 표시, 슬라이더로 환율을 바꾸면 원화 지출, 추가 필요금액, 새 목표금액, 주별 저축액 변화 |
| 3 여행 중 관리 | 현지 금액으로 지출 입력(원화 자동 환산), 공동/개인, 결제자, 1회성 여부, 메모. 지금까지 지출, 남은 예산, 하루 평균, 예상 최종 지출, 초과 경고 |
| 4 공동 여행자금 | 멤버 추가, 입금 기록, 입금 현황 진행바, 예정 지출과 예상 잔액(부족하면 경고) |
| 5 여행 후 정산 | 지출 분류 확인, 멤버별 낸 돈·부담할 돈·차액, 최종 송금 목록 |
| 6 리포트 | 예상 vs 실제 막대그래프, 카테고리별 실제 지출 도넛 그래프, 항목별 차이 표 |

### 정산 규칙

- 공동자금: 멤버마다 입금하고, 공동지출은 공동자금에서 결제합니다.
- 공동지출 전체를 인원으로 나눕니다. 나누어떨어지지 않는 원은 버립니다.
- 남은 공동자금은 인원으로 똑같이 나누어 돌려줍니다. 여기서도 나머지 원은 버리고, 자투리 원은 공동자금에 남깁니다.
- 멤버가 대신 낸 공동지출과 개인지출은 "낸 돈"에 넣고, 개인지출은 대상자의 "부담할 돈"에 넣습니다.
- 차액을 금액이 큰 순서로 짝지어 송금 목록을 만듭니다.

### 금액 표시

모든 금액은 원화 정수로 저장하고, 화면에는 `1,234,000원` 형식으로 보여줍니다.

## 설치

Anaconda Prompt에서 기존 `vibe` 환경을 사용합니다. 프로젝트 규칙에 따라 새 가상환경은 만들지 않습니다.

```bat
conda activate vibe
cd c:\Finance\Tripflow\tripflow
pip install -r requirements.txt
```

필요한 패키지는 `streamlit`, `pandas`, `plotly`, `requests`, `pytest`입니다. 파이썬은 3.10 이상이 필요합니다.

환율은 [Frankfurter](https://api.frankfurter.dev) 공개 API를 씁니다. API 키는 필요 없습니다. 인터넷이 안 되면 캐시나 직접 입력한 환율을 씁니다.

## 실행

```bat
conda activate vibe
cd c:\Finance\Tripflow\tripflow
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열립니다. 왼쪽 메뉴에서 페이지를 고르고, 사이드바에서 여행을 선택합니다.

처음 실행하면 `data/tripflow.db`가 만들어집니다.

### 발표용 샘플 데이터

```bat
conda activate vibe
cd c:\Finance\Tripflow\tripflow
python seed.py
set TRIPFLOW_TODAY=2026-06-20
streamlit run app.py
```

- `seed.py`는 홍콩 3박 4일(2026-10-10 ~ 2026-10-13), 3명(A, B, C) 여행을 넣습니다. 같은 샘플이 이미 있으면 지우고 다시 넣으므로 여러 번 실행해도 괜찮습니다.
- `TRIPFLOW_TODAY`는 기준일을 2026-06-20으로 고정합니다. 출발까지 정확히 16주, 4개월이 남는 상태가 됩니다.
- PowerShell에서는 `$env:TRIPFLOW_TODAY="2026-06-20"`으로 설정합니다.
- 샘플 여행에서 화면에 나오는 주요 숫자는 다음과 같습니다.
  - 예상 여행비 3,000,000원, 1인 목표 1,000,000원, 보유 400,000원이면 필요 저축 600,000원
  - 월 150,000원, 주 37,500원, 4개월(16주)
  - 공동자금 입금 900,000원, 정산 결과 A → C 19,000원, B → C 4,000원
- 1_여행전 페이지의 입력칸은 기본값이 "오늘로부터 60일 뒤"입니다. 샘플 숫자를 보려면 출발일 2026-10-10, 귀국일 2026-10-13, 보유금액 400,000을 직접 입력하세요.
- 시연 전용 DB를 쓰려면 `set TRIPFLOW_DB=c:\경로\demo.db`로 DB 파일 경로를 바꿀 수 있습니다.

### 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `TRIPFLOW_DB` | `data/tripflow.db` | SQLite DB 파일 경로 |
| `TRIPFLOW_TODAY` | 오늘 날짜 | 기준일(YYYY-MM-DD). 저축계획과 여행 진행률 계산에 쓰입니다. |

## 테스트

```bat
conda activate vibe
cd c:\Finance\Tripflow\tripflow
python -m pytest -v
```

계산 함수(`core/`)를 검증하는 테스트 32개가 있습니다. 환율 API는 테스트에서 가짜 응답으로 바꿔 씁니다. 페이지 화면은 자동 테스트가 없고, `streamlit.testing.v1.AppTest`로 직접 확인했습니다.

## 폴더 구조

```
tripflow/
├── app.py              # 시작 화면(제목과 안내 문구). 메뉴는 pages/가 자동으로 만든다.
├── ui.py               # 페이지 공통 헬퍼: 금액 표시, 여행 선택, 환율 캐시, 기준일
├── db.py               # SQLite 테이블 생성과 CRUD 함수
├── seed.py             # 발표용 샘플 데이터 넣기
├── pages/              # Streamlit 페이지 (파일 이름 숫자가 메뉴 순서)
│   ├── 1_여행전.py
│   ├── 2_환율.py
│   ├── 3_여행중.py
│   ├── 4_공동자금.py
│   ├── 5_정산.py
│   └── 6_리포트.py
├── core/               # 계산 함수만 있는 순수 모듈 (Streamlit을 import하지 않음)
│   ├── budget.py       # 예상 여행비, 저축계획, 항공권 가격 재계산
│   ├── fx.py           # 환율 조회(API → 캐시 → 입력값), 원화 환산, 환율 시뮬레이션
│   ├── forecast.py     # 소비속도, 예상 최종 지출, 카테고리 비교
│   ├── fund.py         # 공동자금 입금 현황과 예상 잔액
│   └── settlement.py   # 멤버별 차액과 송금 목록
├── data/
│   ├── prices.json     # 도시·스타일별 항목 단가
│   ├── tripflow.db     # 실행 시 생성되는 DB (git에 올리지 않음)
│   └── fx_cache.json   # 마지막으로 받은 환율 캐시 (실행 시 생성)
├── tests/              # pytest 테스트
├── pytest.ini
├── requirements.txt
├── plan.md             # 구현 계획
├── checklist.md        # 진행 체크리스트
└── context-notes.md    # 설계 결정 기록
```
